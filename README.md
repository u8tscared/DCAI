# Drakkar

Outil de prospection foncière pour un campus IA de 100 MW : terrains constructibles de 12 à 40 ha près des postes RTE 400 et 225 kV, propriétaires, suivi d'appels partagé.

- Site statique (GitHub Pages), comptes et suivi sur Supabase.
- Les données des terrains sont chiffrées (`data.enc`) et ne s'ouvrent qu'après connexion.
- L'inscription demande un code d'accès donné par l'équipe.
